Elf Academy Final Exam: printable Christmas escape room for teenagers

By Paul, creator of Christmas Escape Room · Updated 22 November 2026

Elf Academy Final Exam is a free printable Christmas escape room for teenagers aged 11–16. Players crack an old-phone texting code, Morse code, a missing-vowels puzzle and a Twelve Days of Christmas maths lock to pass the exam. It takes 30–45 minutes for 2–6 players.

The story

Every elf must pass the Elf Academy Final Exam before being allowed into Santa’s workshop. This year the head elf has hidden the exam papers around your house. Find them all and solve each one to earn your place and your prize.

What’s in the game

  1. Exam paper 1: Ancient technology: an old-phone multi-tap code.
  2. Exam paper 2: Signals: Morse code with the key included.
  3. Exam paper 3: Vowel thief: a missing-vowels puzzle.
  4. Exam paper 4: Festive maths: a maths puzzle (triangular numbers).

How to set it up

  1. Print the cards below. Each card prints on its own sheet and the host notes are left off.
  2. Hide each card in the place shown in its host note and in the answer key. Start from the last card and work backwards.
  3. Put the prize and the final card in a bag or box. Lock it with a 3-digit padlock set to 364, or have the host check the code.
  4. Start the escape room timer and hand Card 1 to the players.

Make it easier or harder

  • Easier: say the first card is a phone keypad code and let players use a calculator for the final puzzle.
  • Harder: remove the Morse key and hide it in a different room, and set a 30-minute limit.

Frequently asked questions

What’s a good Christmas escape room for teenagers?

Elf Academy Final Exam is a free printable game built for ages 11–16. It uses old-phone texting, Morse code, a missing-vowels puzzle and a maths lock, so it’s harder than kids’ games but not too long. It takes 30–45 minutes.

Can teenagers set it up themselves?

Yes. One teen can host for younger siblings, or a parent can hide the cards in 10 minutes.

Can adults play too?

Yes. Adults can join a teen team, or race them with a second copy.

What if they get stuck on the maths?

Hint: work out how many gifts arrive each day (1, 3, 6, 10…) and add them up. The answer is 364.
