Tips for hosting

  • Print on card if you can. Clue cards survive little hands better.
  • Put the timer on the TV for atmosphere.
  • Give each team three hint tokens; spending one costs two minutes.
  • Finish with a printable certificate.

Frequently asked questions

What do I need for a printable Christmas escape room?

A printer, A4 paper, scissors and a few hiding places around the house. Our printables don’t need padlocks or special props.

Can adults play a printable Christmas escape room?

Yes. Adults can play the standard version against the clock, or use the ‘make it harder’ tips on each game page to add a time limit and remove hints.

Is there an answer key?

Yes. Every printable has a full answer key on its own page so the host can help if players get stuck.
