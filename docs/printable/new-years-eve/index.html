New Year’s Eve escape room: a printable countdown game

By Paul, creator of Christmas Escape Room · Updated 22 November 2026

Countdown to Midnight is a free printable New Year’s Eve escape room for ages 10 to adult. Players crack a Roman numeral clock code, a backwards message, a number code and a countdown maths lock to find the party poppers before midnight. It takes 30–45 minutes.

The story

The party poppers have been locked away and midnight is coming. Follow the clues from the clock to the sideboard and the fridge, crack the countdown code and find the poppers in time to see in the New Year.

What’s in the game

  1. Time is ticking: a Roman numeral code.
  2. Out of order: a backwards message.
  3. Keep it chilled: an A=1 number code.
  4. The countdown: a maths lock.

How to set it up

  1. Print the cards below. Each card prints on its own sheet and the host notes are left off.
  2. Hide each card in the place shown in its host note and in the answer key. Start from the last card and work backwards.
  3. Put the final card in a box with party poppers. Lock it with 055 on a 3-digit padlock, or have the host check the code.
  4. Start the escape room timer and hand Card 1 to the players.

Make it easier or harder

  • Easier: give the Roman numeral key: I=1, V=5, X=10.
  • Harder: remove the A–Z table and the Roman numeral hint, and start at 11.30pm.

Frequently asked questions

What can we do on New Year’s Eve at home?

Play a New Year’s Eve escape room. Countdown to Midnight takes 30–45 minutes; start around 11pm and finish just in time to pop the party poppers at midnight.

Is it suitable for adults?

Yes. Ages 10 to adult. For a harder adult version, take away the hints and set a 20-minute limit.

Do I need a padlock?

No. A padlock set to 055 is fun, but the host can check the answer.

Can children play?

Children aged 10+ can play alone; younger children can join a team with an adult.
