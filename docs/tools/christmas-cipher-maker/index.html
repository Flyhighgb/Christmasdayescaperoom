Frequently asked questions

What is a pigpen cipher?

A pigpen cipher swaps each letter for a shape taken from a noughts-and-crosses grid or an X, with or without a dot. It looks like secret symbols but is easy to decode with the key, which makes it ideal for children’s escape rooms.

What is a Caesar cipher?

A Caesar cipher moves every letter a set number of places along the alphabet. With a shift of 3, A becomes D and CHIMNEY becomes FKLPQHB.

Which code is best for young children?

The number code (A=1, B=2) is easiest for ages 5–7. Pigpen suits ages 7+, and a Caesar shift suits ages 9+.

Can I print the codes?

Yes. Press ‘Print code and key’ to print the coded message together with a decoding key for the players.
